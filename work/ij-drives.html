IJ-Drives

Multi-modal Nigerian transport marketplace covering land, sea, air and rail.

Unpublished JavaScript HTML/CSS Google Maps IndexedDB
GitHub repository →

Overview

IJ-Drives is a multi-modal Nigerian transport concept that brings interstate road travel, domestic ferry routes, flights, and passenger rail under one clear interface.

My role

Frontend developer. Created the UI flows, dual light and dark themes, multi-modal transport tabs, search forms, and offline client caching.

The problem

Nigerian travellers usually have to check separate operator websites or visit physical motor parks to compare prices and departure times across buses, rail, and flights. IJ-Drives lets travellers compare multi-modal transit options on common routes such as Lagos to Ibadan or Abuja to Kaduna in one view.

Key decisions and rationale

Vanilla JavaScript zero-dependency architecture

Built the client interface entirely with vanilla JavaScript and clean CSS. This keeps initial page weight low, which matters on variable 3G and 4G mobile connections.

Client-side IndexedDB caching

Used IndexedDB to save recent route searches and terminal locations locally. Users can still view their search history and terminal notes if their phone signal drops in transit.

Native light and dark mode UI

Built light and dark themes using CSS variables with automatic system preference detection, making the interface comfortable to read both in direct sunlight and at night.

Architecture

Modular vanilla JavaScript components paired with CSS custom properties. Google Maps JavaScript API handles geographic waypoint selection, route distance calculations, and terminal locations, backed by browser IndexedDB storage for offline search caching.

Technologies used

Vanilla JavaScript HTML5 CSS3 Custom Properties Google Maps API IndexedDB
