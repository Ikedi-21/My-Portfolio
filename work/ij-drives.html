IJ-Drives

Multi-modal Nigerian transport marketplace covering land, sea, air and rail.

Unpublished FastAPI Python SQLAlchemy 2.0 (Async) PostgreSQL Docker Leaflet
GitHub repository →

Overview

IJ-Drives is a multi-modal transport marketplace demo for Nigeria. Users search routes across land, rail, sea, and air, pay from a digital wallet, and book tickets through an interactive 4-step flow.

My role

Full-stack developer. Built the async FastAPI backend, database models, transaction locks, and authentication, alongside the responsive multi-modal frontend and route maps.

The problem

Nigerian travellers usually have to check separate operator websites or visit physical motor parks to compare prices and departure times across buses, rail, and flights. IJ-Drives lets travellers compare multi-modal transit options on common routes such as Lagos to Ibadan or Abuja to Kaduna in one view.

Key decisions and rationale

Async FastAPI backend with a layered architecture

Structured the backend across routers, domain services, SQL repositories, and Pydantic schemas for clear separation of concerns and robust type contracts.

Row-level locking for double-spend prevention

Protected wallet debits and ticket bookings with row-level locking (SELECT ... FOR UPDATE) so concurrent requests cannot double-spend funds or overbook seats.

JWT authentication with bcrypt password hashing

Secured user accounts and session authorization with signed JSON Web Tokens and salted bcrypt password hashing.

Async pytest suite with atomic rollback validation

Built an automated async pytest suite covering authentication flows, wallet limit constraints, and atomic booking transactions with rollback verification.

Architecture

Built with an asynchronous FastAPI backend and a vanilla JavaScript frontend. PostgreSQL handles data persistence via SQLAlchemy 2.0 with aiosqlite for tests, Leaflet with Stadia Maps visualises transport routes, and Docker Compose manages local multi-container services.

Technologies used

FastAPI Python SQLAlchemy 2.0 (Async) Pydantic v2 PostgreSQL SQLite (aiosqlite) JWT auth bcrypt Docker pytest Leaflet Stadia Maps Vanilla JS/HTML/CSS
