Athenaeum-Ikedi

Academic library management system built with Python and Django 6.1.

Published Python Django 6.1 PostgreSQL Railway Strict CSP
Live site → GitHub repository →

Overview

Athenaeum-Ikedi is an academic library management application designed for cataloguing books, managing patron borrowing, handling active reservation queues, computing overdue fines, and recording audit logs.

My role

Lead backend developer. Designed the data models, transactional workflows, concurrency locks, security policies, and Railway deployment.

The problem

In college libraries, multiple students frequently request the final available copy of a course textbook at the same time. Unchecked read-and-write cycles create inventory mismatches and double-lends. The system required guaranteed transaction safety along with verifiable audit trails.

Key decisions and rationale

Separating business rules from data services

Placed borrowing rules, hold limits, and fine formulas into pure Python functions. This structure keeps core rules straightforward to unit test without spinning up database test fixtures.

Atomic transactions with row-level locks

Wrapped checkout and reservation actions in transaction.atomic() blocks using select_for_update(). This stops race conditions whenever multiple users try to reserve or borrow the same copy at once.

Immutable audit logs

Created an append-only transaction ledger that logs checkouts, returns, fine payments, and hold changes with timestamps and user IDs for clear traceability.

Architecture

Built with Python and Django 6.1 on PostgreSQL. The security setup includes strict Content Security Policy (CSP) headers, CSRF verification, session protection, and Docker containerization hosted on Railway.
