LUMEN

Discovery platform for movies, books, manga and comics.

Published React 19 Vite React Router Supabase Paystack Vercel Serverless
Live site → GitHub repository →

Overview

LUMEN is a digital discovery platform for movies, books, manga, and comics. It features curated catalogues across categories, user wishlists, carts, creator payouts, an admin dashboard, and an internal coin wallet powered by Paystack payments.

My role

Sole developer. Responsible for full-stack architecture, database design, payment integration, serverless functions, and frontend engineering from brief to deployment.

The problem

Entertainment discovery is fragmented across separate single-medium platforms. Readers and viewers juggle different services with separate wishlists and varied checkouts. LUMEN brings these formats into a unified interface and simplifies micro-transactions through a coin wallet system.

Key decisions and rationale

Role-based access control via Supabase RLS

Used PostgreSQL Row Level Security (RLS) policies to govern admin privileges, creator catalogues, and buyer actions directly at the database layer. This keeps permissions clean without requiring a custom authentication service.

Server-side Paystack verification

Wallet top-ups are validated through Vercel serverless functions before crediting coins. The client never credits the wallet directly, preventing client-side spoofing and altered payment payloads.

Coin wallet abstraction

Separated item pricing from direct currency transactions by using an internal coin ledger. This allows bundles, promos, and rewards without triggering credit card gateway fees on every single purchase.

Architecture

Frontend built with React 19 and Vite, hosted on Vercel with client-side routing via React Router. The persistence and authentication tier is handled by Supabase (PostgreSQL with Row Level Security and file storage). Serverless functions on Vercel verify webhooks and securely process Paystack payment confirmations.
