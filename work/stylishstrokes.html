StylishStrokes

Single-page calligraphy archive with an interactive stroke engine and live tracing tool.

Unpublished React Vite Tailwind CSS HTML5 Canvas Team Project
GitHub repository →

Overview

StylishStrokes is a digital calligraphy practice platform. It includes an interactive "Ink Lab" canvas where users can adjust nib angles, control ink flow, and practice lettering using a guided live tracing tool.

My role and team credit

StylishStrokes was a collaborative project built by a team of five. I served as the Lead UI Designer. I designed the dark editorial interface, color palettes, and stroke adjustment controls, working closely with our frontend engineers to connect the controls to the HTML5 canvas engine.

The problem

Calligraphy is a tactile craft, making it hard to recreate in a web browser. Most online drawing tools feel generic because they lack nib angles, pressure variation, and stroke guides. Our goal was to build a clean web tool where users can practice letterforms with real-time feedback.

Key decisions and rationale

Dark theme focused on ink contrast

Designed a dark charcoal layout paired with gold and green ink colors. The high contrast makes stroke edges, angle variations, and line thickness easy to see as you write.

HTML5 Canvas engine with velocity tracking

Connected mouse and touch movement to velocity calculations in the canvas. This mimics the thinning and thickening of real fountain pen strokes without lagging on modern browsers.

Vector overlays for guided tracing

Placed SVG letterform paths behind the drawing canvas so users can trace practice words such as 'Flow', giving beginners immediate visual guidance on letter proportion.

Architecture

Single-page React application bundled with Vite. Component styling is handled with Tailwind CSS utilities, with custom React hooks managing the canvas drawing loop, color selection, and letter tracing guides.
