StylishStrokes

Single-page calligraphy archive with an interactive stroke engine and live tracing tool.

Unpublished React Vite Tailwind CSS HTML5 Canvas Team Project
GitHub repository →

Overview

StylishStrokes is a specialized digital calligraphy exploration platform. It provides learners and enthusiasts with an interactive "Ink Lab" canvas stroke engine, nib angle and line-width adjustments, and an assisted live tracing feature that guides hand cadence and fluid penmanship.

My role & team credit

StylishStrokes was created as a collaborative five-person team project. I served as the Lead UI Designer — spearheading the aesthetic direction, layout hierarchy, dark typographic theme, and the interface controls for stroke parameters, while working closely with team engineers on canvas integration.

The problem

Calligraphy is traditionally tactile, making digital education difficult. Standard drawing tools feel synthetic because they lack pressure simulation, nib rotation angles, and rhythm guides. The project goal was to build a browser-accessible environment that preserves the fluid elegance of physical ink and provides real-time letterform tracing.

Key decisions & rationale

Editorial dark aesthetic for ink contrast

Designed a rich, deep black and charcoal palette with gold and vibrant green accent inks. High visual contrast spotlighted the subtle stroke variations, opacity bleeds, and ink texture.

HTML5 Canvas stroke engine with velocity interpolation

Integrated dynamic canvas drawing listeners with stroke velocity calculations to replicate varying nib thickness without performance stutter.

Vector overlay guide for guided tracing

Constructed scalable SVG letterform paths behind the interactive canvas, enabling users to trace practice words such as 'Flow' with precise path bounds and immediate stroke feedback.

Architecture

Single-page React application bundled with Vite. Styling constructed using Tailwind CSS utilities with specialized canvas context hooks for real-time brush rendering, colour sampling, and tracing path coordinate mapping.
